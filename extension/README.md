# 本机网页 AI 任务桥扩展

这是可加载的 Chromium Manifest V3 源码。只支持 `chatgpt.com`、`chat.deepseek.com`、`gemini.google.com` 的普通聊天页；**三站 DOM 选择器尚未真实页面联测，不能宣称三站已可用**。没有安装到本机浏览器，也没有发送任何真实网页消息。

## 使用

1. 启动上级目录的本机桥。Chrome/Edge 120 或以上版本可在扩展开发者模式中加载本目录。
2. 在扩展设置中输入本机桥配对码。本机桥地址默认 `http://127.0.0.1:32145`（与 Harness 插件默认端口一致）；若改过插件端口，在设置页填新端口，或直接点“检查本机桥在线”让它自动找到并记住。在线检查只检查服务，不验证配对码。
3. 打开已经登录的独立聊天页，确保没有草稿、没有生成中的回答。首次安装后刷新页面，点击扩展弹窗的“连接当前聊天”，指定唯一英文别名。
4. 等待弹窗显示本机桥心跳确认，再由 DSH 使用这个别名派任务。保持标签页打开；接着派发的任务继续使用同一对话。
5. 控件定位失败时，在高级设置修改五个 CSS 选择器。断开再连接后用于新任务。先用独立对话验证小任务及追问；不要直接交给长任务。

## 发送与完成边界

- 未主动连接的页面仅向扩展后台查询绑定状态，不领取任务，也不读取聊天内容。
- 发送前检查唯一输入框、唯一发送按钮、空草稿、没有停止生成按钮。先持久保存发送尝试，再填入文本；点击前再次核实本机许可。每个任务只有一次 `click()`，没有回车降级或重试。
- 记录发送前助手消息的数量和标识，不复制旧回答。只接受本次新增且唯一的助手消息；原消息重排、多个新回复块、导航到其他对话都会停止确认。
- 完成必须同时满足：本次新答复、观察到生成控件出现后消失、该新消息内唯一完成控件、输入框已恢复、文本稳定至少2秒。稳定文字本身不算完成。无法确认、刷新、超时（10分钟）或回答超过120000字符时报告 `uncertain`，不冒充完整结果。
- 首页第一次发送导致的同文档新对话地址变更可以接纳一次；换已有对话、跨站、刷新不接续发送。完整页面重载即使到了新对话，也保守标为未确认。
- 如果任务已经领取但响应传输丢失，后续服务端只返回 `pending`；扩展标为未确认，不索回提示词重发。
- 用户修改输入框、点击发送/停止时，扩展暂停本次结果确认，不阻止用户操作。

## 人工解除

“断开”只停止扩展派发，不替用户点击网页停止按钮。请先检查网页任务是否已发送、是否仍在生成，再点击“我已检查网页，解除挂起任务”。后台先撤销本地发送许可，并等待页面取消确认，然后调用 `/v1/resolve`；不会补发原任务。旧页面无法确认取消时，先关闭该标签页再解除。解除后需要重新连接指定聊天。

## 权限及实现范围

只使用 `storage`、`activeTab`，三个聊天域和回环地址 host 权限。Chrome host 匹配不按端口限制；扩展 CSP 与请求地址都按回环任意端口放行（`connect-src http://127.0.0.1:*`），实际端口默认 32145，可在设置页指定或由在线检查自动发现。拒绝重定向。无 `debugger`、`cookies`、`all_urls` 或外部脚本，无网页私有接口或验证码绕过。

配对码保存在 `chrome.storage.local`，访问级别为 `TRUSTED_CONTEXTS`，仅扩展可信页面及后台可访问，不返回给内容脚本。DOM 文本只作文本，不经 `innerHTML` 或 `eval` 执行。扩展不访问项目文件。

约2秒的页面心跳用于唤醒后台；浏览器冻结、休眠或丢弃标签页会使其延后或停止，不能承诺常驻或无人值守可靠性。站点改版、工具型回答、思考区分块以及用户同时操作都可能触发保守停止，需要实际页面联测。

实现依据：[Chrome跨域请求](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)、[内容脚本](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[消息传递](https://developer.chrome.com/docs/extensions/develop/concepts/messaging)。
